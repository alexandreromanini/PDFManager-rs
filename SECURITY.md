# Security policy

## Supported versions

Only the [latest release](https://github.com/alexandreromanini/PDFManager-rs/releases/latest) receives
security fixes. PDFManager updates itself: accept the update when it is offered.

## Reporting a vulnerability

Please **do not open a public issue** for a security problem (for example a PDF that makes the
application run code, a signature check that can be fooled, or a password protection that can
be bypassed).

Report it privately instead, from the **Security** tab of this repository:
[Report a vulnerability](https://github.com/alexandreromanini/PDFManager-rs/security/advisories/new).
Include the version, the steps to reproduce and, if possible, a sample file.

You will receive an answer within a week. Once the issue is fixed and a new version is
released, the advisory is published and you are credited, unless you prefer otherwise.
